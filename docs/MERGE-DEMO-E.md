# Merge Demo E

- A three-tier example application built with Next.js, Express, and PostgreSQL.
- The full stack starts with a single `docker compose up --build` command.
- Database schema is managed through versioned node-pg-migrate migrations in `src/db/`.
- Cloud infrastructure is defined as code using Terraform targeting Google Cloud Platform.
- Serves as a reference for containerised three-tier application development and deployment.
