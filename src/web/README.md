# Web Frontend

This is the Next.js frontend for the three-tier application. See the main [README.md](../../README.md) for project documentation.

## Development

The frontend is built with Next.js 16, React 19, and Tailwind CSS. It communicates with the Express API at `http://api:3001` (or `http://localhost:3001` when running locally).

When running via Docker Compose, the web service is exposed on port 3000.
